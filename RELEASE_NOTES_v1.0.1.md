# Release Notes - v1.0.1

## 🚀 New Features

### 📝 Fill in the Blank Tool
- **Smart AI Quizzes**: A brand new interactive tool that generates fill-in-the-blank questions based on your level.
- **Custom Topics**: Enter any topic (e.g., "Space", "History") to generate personalized quizzes instantly.
- **25+ Template Topics**: Ready-to-use topics covering Grammar, Vocabulary, and Everyday German.
- **Instant Feedback**: Get immediate corrections and explanations for every answer.
- **Score Tracking**: Track your performance with detailed result summaries.

### 🔊 Enhanced Flashcards
- **Audio Pronunciation**: Added speaker buttons to German example sentences in Flashcards. Now you can hear the correct pronunciation of context sentences!

## 🎨 UI/UX Improvements

### **Home Screen Redesign**
- **Smart Learning Grid**: Replaced the horizontal scroll with a cleaner 2x2 grid layout for better visibility of all tools (Snap, Stories, Flashcards, Fill in Blank).
- **Streamlined Interface**: Removed "Daily Challenges" and "Your Progress" sections for a less cluttered home experience.

### **Profile & Settings**
- **Simplified Settings**: Hidden advanced developer options ("Seed Database", "Audio & Feedback", "Notifications") to provide a cleaner user profile.

## 🔧 Under the Hood
- **Performance**: Optimized list rendering for smoother scrolling.
- **Theming**: Unified color palette across new tools for consistent dark/light mode support.
- **Bug Fixes**: Resolved layout issues in the Tools tab and improved navigation responsiveness.
