# HalloDeutsch v1.0.0 🇩🇪

> **First production release!** Your comprehensive German learning companion.

## ✨ Features

### 📚 Comprehensive Curriculum (A1-B2)
- **4 CEFR Levels**: Progress from complete beginner (A1) to upper intermediate (B2)
- **Structured Modules**: Each level divided into themed modules with clear learning objectives
- **Progress Tracking**: Track your completion across all levels

### 📝 Grammar Reference Tables
- **18+ Grammar Topics**: From articles and verb conjugation to Konjunktiv and passive voice
- **Interactive Tables**: Quick reference tables for declensions, conjugations, and more
- **Detailed Explanations**: Each topic includes:
  - Clear explanations with examples
  - Key rules to remember
  - Common mistakes to avoid
  - Practical tips

### 🗣️ AI Chat Tutor
- **Conversational Practice**: Chat with an AI tutor in German
- **Context-Aware Responses**: Get corrections and explanations
- **Natural Dialogue**: Practice real-world conversation scenarios

### 🔤 Vocabulary Study
- **1000+ Words**: Organized by topic and level
- **Flashcard Mode**: Swipe-based learning with spaced repetition
- **Audio Pronunciation**: Hear native pronunciation for every word
- **Smart Dictionary**: Search and explore German vocabulary

### 📖 Reading Practice
- **Graded Stories**: Level-appropriate reading materials
- **Interactive Sentences**: Tap words for translations
- **Comprehension Focus**: Build reading fluency naturally

### 🎯 Practice Tools
- **Vocabulary Flashcards**: Flip cards with German/English
- **Grammar Exercises**: Reinforce concepts with interactive drills
- **Sentence Formation**: Build sentences using learned vocabulary

### 🔧 Additional Tools
- **Snap & Learn**: Use camera to identify objects and learn German names
- **Grammar Tables**: Quick reference for all grammar rules
- **Pronunciation Guide**: Learn proper German pronunciation

### 🔄 In-App Updates
- **Auto Update Check**: Automatically checks for new versions
- **Release Notes**: See what's new before updating
- **One-Tap Install**: Download and install updates directly

### ⚙️ Settings & Preferences
- **Dark/Light Mode**: Choose your preferred theme
- **TTS Voice Model**: Optional high-quality offline German voice
- **Progress Reset**: Start fresh whenever you want
- **Profile Management**: Track your learning journey

## 🛠️ Technical Details

- **Offline Support**: Core content available without internet
- **Firebase Backend**: Secure cloud sync and authentication
- **Google Sign-In**: Easy account creation and login
- **Auto Content Sync**: Content updates automatically on launch

## 📱 Requirements

- Android 8.0 (API 24) or higher
- ~105 MB storage space
- Internet connection for:
  - AI Chat features
  - Account sync
  - Content updates

## 🚀 Getting Started

1. Install the APK
2. Sign in with Google (optional but recommended for progress sync)
3. Select your current German level
4. Start learning!

## 📋 Known Limitations

- iOS version not yet available
- Offline mode requires initial content sync
